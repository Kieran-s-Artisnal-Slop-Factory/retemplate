# Using a template

*(Stub — finished in Phase 11. The get-started page inside each template,
`templates/<name>/docs/index.html`, is the same information with live
examples.)*

1. Copy `templates/<name>/` into your project.
2. Keep the **install set**: `css/`, `js/theme.js`, `fonts/` (if present),
   `assets/`. Delete the rest (`index.html`, `blogpost.html`, `forms.html`,
   `sidebar.html`, `docs/`, `example/`, `js/copy.js`) — or start from
   `example/`, which is a complete three-page site.
3. Put the head block from the template README at the top of every page.
4. Write HTML using the classes documented under `docs/components/`.

No build step, no framework, no dependencies. Browser floor: Baseline 2024.
