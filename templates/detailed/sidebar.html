The other layout

The overview, with a sidebar

Every template ships two layouts. The navbar layout carries the overview, the blog post and the forms page; this page and the docs use the sidebar layout. The top bar is the same black band as the navbar. On a wide screen the sidebar is a column with gold-ruled group headings; on a narrow one it is a drawer behind the menu button, edged in a double gold rule, and it closes on Esc or a tap outside.

Layout

Two rows, and above 64rem two columns

The top bar spans both columns and stays put; the sidebar is a sticky column with its own scrollbar; the page scrolls under it. Below 64rem the sidebar carries the popover attribute, so the menu button is a real button and the browser supplies the backdrop and the dismissal.

What the column is made of

Groups fold

Each navigation group is a <details>, open by default, with a tracked gold heading. Close the ones you do not need.

The current page

The link to the page you are on carries aria-current="page", which draws its gold edge.

Same content, either way

Nothing on this page needs the sidebar. Swap the shell and the page still works.

Docs
Can the sidebar collapse on a wide screen?

Not in this version. The drawer behaviour is for narrow screens only; on a wide screen the column is always there.

Does the drawer remember being open?

No. It is a popover: it opens when asked and closes when dismissed, and there is nothing to remember.
