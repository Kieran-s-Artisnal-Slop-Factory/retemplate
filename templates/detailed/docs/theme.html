Tokens and the palette

Everything in Detailed is coloured through tokens. Nineteen palette slots hold the actual colours, each as a light and dark pair; a layer of semantic tokens maps roles onto them; components only ever name a role. This is retoken's system, so the palette below is also a retoken theme.

Use this palette in retoken

Copy the block below into your retoken site's theme.css after the existing palettes, then select it with <html data-theme="detailed"> or pick it in the theme editor, which discovers palettes from the stylesheet. Colours travel; fonts, radii and spacing do not — set those in the editor.

:root[data-theme='detailed'],
[data-theme='detailed'] {
  --pal-bg0: light-dark(#f3ead8, #0d1220);
  --pal-bg0-soft: light-dark(#faf5e8, #131a2c);
  --pal-bg1: light-dark(#eadfc6, #1a2238);
  --pal-bg2: light-dark(#d3c39c, #34405c);
  --pal-bg3: light-dark(#b8a374, #4d5878);

  --pal-fg: light-dark(#14121a, #efe6d2);
  --pal-fg-muted: light-dark(#5c5142, #b9ae94);
  --pal-gray: light-dark(#8a7d66, #7f8699);

  --pal-red: light-dark(#a3342a, #e08a7a);
  --pal-green: light-dark(#3f6b3a, #9cc98a);
  --pal-yellow: light-dark(#8a6414, #e2c46b);
  --pal-blue: light-dark(#2f5375, #8fb0dc);
  --pal-purple: light-dark(#5f4270, #b79ad0);
  --pal-aqua: light-dark(#2b6a66, #8dc7c0);

  --pal-accent: light-dark(#7a5a12, #d4af37);
  --pal-accent-strong: light-dark(#5c4309, #e8c65a);
  --pal-on-accent: light-dark(#f3ead8, #0d1220);

  --pal-shadow-1: light-dark(rgb(20 18 26 / 0.12), rgb(0 0 0 / 0.5));
  --pal-shadow-2: light-dark(rgb(20 18 26 / 0.22), rgb(0 0 0 / 0.65));
}

Two things the block deliberately does not do: it never declares a bare :root (pasted into retoken that would override the site's default palette), and it never declares fonts (their url()s would break outside this folder). That is why every page here sets data-theme="detailed" on <html>.

Light and dark

color-scheme: light dark on :root lets the browser resolve each light-dark() pair from the visitor's preference. The toggle pins color-scheme on <html> instead; the third click unpins it. For things that are not colours — a texture, an ornament, content — theme.js keeps html[data-scheme] equal to the scheme in effect, so CSS can select on it.
