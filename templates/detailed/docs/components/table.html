Component

Table

A data table in a wrapper that scrolls sideways when the table is wider than the page. The head row sits on a gold double rule. Detailed adds a second dress for it: the menu.

Preview

<div class="table-wrap">
  <table class="data-table">
    <thead><tr><th>Name</th><th>Role</th><th>Status</th></tr></thead>
    <tbody>
      <tr><td>Ada</td><td>Analyst</td><td><span class="badge badge-active">Active</span></td></tr>
      <tr><td>Grace</td><td>Compiler</td><td><span class="badge badge-done">Done</span></td></tr>
      <tr><td>Margaret</td><td>Engineer</td><td><span class="badge">Draft</span></td></tr>
    </tbody>
  </table>
</div>

Variants

The menu, Detailed's own

Add detailed-menu to the wrapper and the table sets like a bill of fare: no box, the head row hidden but still read aloud, course headings as centred capitals between two gold hairlines, a dotted leader from each dish to its price, and the price in tracked capitals on the right. A course heading is a row with class="detailed-course" holding one <th colspan="2" scope="colgroup">. Put the dish name in <strong> and its description in <span class="small">.

<div class="table-wrap detailed-menu">
  <table class="data-table">
    <thead><tr><th>Dish</th><th>Price</th></tr></thead>
    <tbody>
      <tr class="detailed-course"><th colspan="2" scope="colgroup">To begin</th></tr>
      <tr><td><strong>Quay oysters</strong> <span class="small">Six, with a shallot vinegar</span></td><td>18</td></tr>
      <tr><td><strong>Smoked eel</strong> <span class="small">Beetroot, horseradish, rye</span></td><td>14</td></tr>
      <tr class="detailed-course"><th colspan="2" scope="colgroup">Puddings</th></tr>
      <tr><td><strong>Custard tart</strong> <span class="small">As served in 1931</span></td><td>9</td></tr>
    </tbody>
  </table>
</div>

Classes

The rules live in css/global.css under /* == table == */.

ClassPurpose
.table-wrapBorder, radius, horizontal scrolling
.data-tableSmall type, gold-ruled head, hover rows, no last border
.detailed-menuDetailed only, on the wrapper: the bill-of-fare treatment (rules under /* == flare == */)
.detailed-courseDetailed only, on a row: a course heading between gold hairlines

Notes

  • Use <th> in the head row, and scope="row" on a first-column header if rows have one.
  • Tables inside .prose get the same treatment without the classes.
  • The menu keeps its <thead>, visually hidden, so column headers are still announced. Another template ignores both menu classes and shows an ordinary table.
