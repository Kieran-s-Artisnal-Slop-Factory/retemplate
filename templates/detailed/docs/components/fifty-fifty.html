Fifty-fifty

An image on one half and text on the other, with a heading, a paragraph and a button. One class mirrors it.

Preview

<section class="fifty-fifty">
  <figure><img src="../../assets/fifty.svg" alt="" width="900" height="600"></figure>
  <div class="fifty-fifty-body">
    <p class="kicker">Kicker</p>
    <h2>A heading for the block</h2>
    <p>A paragraph that says the one thing this block is for.</p>
    <a class="btn btn-primary" href="#">Call to action</a>
  </div>
</section>

Classes

The rules live in css/global.css under /* == fifty-fifty == */.

ClassPurpose
.fifty-fiftyTwo-column grid above 48rem; one column below
figureThe image half; the image covers it
.fifty-fifty-bodyThe text half, padded
.fifty-fifty-reverseMoves the image to the right on wide screens

Notes

  • On narrow screens the image always comes first, whichever side it takes on wide ones.
  • Give the image real dimensions (width, height) to avoid layout shift.
