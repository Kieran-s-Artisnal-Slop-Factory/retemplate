Reading a component page

Each page has the same shape. Preview is the component itself, rendered. Markup is exactly what you see, escaped, with a copy button; a checker compares the two, so they cannot drift. Variants repeat the pair for each modifier. Classes names the section of global.css where the rules live. Notes says how it behaves, what the keyboard does, and whether any script is involved (almost never).
