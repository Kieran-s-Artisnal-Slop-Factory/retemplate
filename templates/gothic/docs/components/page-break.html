Component

Page break

A thematic break. The bare <hr> is a rule; .page-break is the template's ornament, which in Gothic is tracery: a quatrefoil between two rules. A second rule, the arcade, is Gothic's own.

Arcade rule (Gothic)

A row of small pointed arches across the whole column. Use it where the page changes subject, and the quatrefoil for a break inside one subject. It is still an <hr>; another template would render it as a plain rule.

Classes

The rules live in css/global.css under /* == page-break == */.

ClassPurpose
hrA one-pixel rule with vertical space
hr.page-breakNo rule; the tracery ornament drawn with ::after as a mask filled with --gothic-ornament

Notes

  • Both are the same element, so both mean the same thing to a screen reader: a break between sections.
  • Both ornaments are mask-images over a background colour, so they take the ornament colour: crimson by day, gold by night. The drawings are the --gothic-tracery and --gothic-rule tokens in theme.css; redraw them there.
