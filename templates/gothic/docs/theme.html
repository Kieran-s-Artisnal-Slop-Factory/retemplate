Tokens and the palette

Everything in Gothic is coloured through tokens. Nineteen palette slots hold the actual colours, each as a light and dark pair; a layer of semantic tokens maps roles onto them; components only ever name a role. This is retoken's system, so the palette below is also a retoken theme.

Use this palette in retoken

Copy the block below into your retoken site's theme.css after the existing palettes, then select it with <html data-theme="gothic"> or pick it in the theme editor, which discovers palettes from the stylesheet. Colours travel; fonts, radii and spacing do not: set those in the editor.

:root[data-theme='gothic'],
[data-theme='gothic'] {
  --pal-bg0: light-dark(#e9e5dc, #111014);
  --pal-bg0-soft: light-dark(#f2efe7, #1a181e);
  --pal-bg1: light-dark(#dcd7cb, #242128);
  --pal-bg2: light-dark(#bcb5a6, #3b363f);
  --pal-bg3: light-dark(#948c7c, #57515e);

  --pal-fg: light-dark(#23222a, #e6e1d6);
  --pal-fg-muted: light-dark(#5c5866, #aaa39b);
  --pal-gray: light-dark(#7d7885, #7b7580);

  --pal-red: light-dark(#8e2230, #d46a72);
  --pal-green: light-dark(#35603f, #8fb894);
  --pal-yellow: light-dark(#6a500d, #d9b866);
  --pal-blue: light-dark(#3f5a82, #8fa6c9);
  --pal-purple: light-dark(#5b4a7c, #b09ad0);
  --pal-aqua: light-dark(#2f6a72, #86bcc0);

  --pal-accent: light-dark(#7a1f2b, #c9a24c);
  --pal-accent-strong: light-dark(#5e1520, #e0bf6b);
  --pal-on-accent: light-dark(#f2efe7, #111014);

  --pal-shadow-1: light-dark(rgb(35 34 42 / 0.14), rgb(0 0 0 / 0.5));
  --pal-shadow-2: light-dark(rgb(35 34 42 / 0.26), rgb(0 0 0 / 0.7));
}

Two things the block deliberately does not do: it never declares a bare :root (pasted into retoken that would override the site's default palette), and it never declares fonts (their url()s would break outside this folder). That is why every page here sets data-theme="gothic" on <html>.

Light and dark

color-scheme: light dark on :root lets the browser resolve each light-dark() pair from the visitor's preference. The toggle pins color-scheme on <html> instead; the third click unpins it. For things that are not colours (a texture, an ornament, content) theme.js keeps html[data-scheme] equal to the scheme in effect, so CSS can select on it.
