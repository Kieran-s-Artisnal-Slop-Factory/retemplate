Tokens and the palette

Everything in Termy is coloured through tokens. Nineteen palette slots hold the actual colours, each as a light and dark pair; a layer of semantic tokens maps roles onto them; components only ever name a role. This is retoken's system, so the palette below is also a retoken theme.

Use this palette in retoken

Copy the block below into your retoken site's theme.css after the existing palettes, then select it with <html data-theme="termy"> or pick it in the theme editor, which discovers palettes from the stylesheet. Colours travel; fonts, radii and spacing do not; set those in the editor.

:root[data-theme='termy'],
[data-theme='termy'] {
  --pal-bg0: light-dark(#0a1f13, #ffffff);
  --pal-bg0-soft: light-dark(#0d2618, #fafafa);
  --pal-bg1: light-dark(#12301f, #f0f0f0);
  --pal-bg2: light-dark(#1c4530, #d6d6d6);
  --pal-bg3: light-dark(#2f6a4a, #a8a8a8);

  --pal-fg: light-dark(#c9f5d3, #111111);
  --pal-fg-muted: light-dark(#7fcf9a, #555555);
  --pal-gray: light-dark(#5a9a72, #8a8a8a);

  --pal-red: light-dark(#ff7b72, #b3001b);
  --pal-green: light-dark(#5cff8a, #0b6e2a);
  --pal-yellow: light-dark(#ffd75e, #7a5200);
  --pal-blue: light-dark(#6ec6ff, #0b4fa8);
  --pal-purple: light-dark(#d3a6ff, #6b2fb3);
  --pal-aqua: light-dark(#5ff2e0, #007a70);

  --pal-accent: light-dark(#5cff8a, #0b6e2a);
  --pal-accent-strong: light-dark(#9dffb8, #084f1f);
  --pal-on-accent: light-dark(#0a1f13, #ffffff);

  --pal-shadow-1: light-dark(rgb(92 255 138 / 0.35), rgb(17 17 17 / 0.2));
  --pal-shadow-2: light-dark(rgb(92 255 138 / 0.55), rgb(17 17 17 / 0.85));
}

Two things the block deliberately does not do: it never declares a bare :root (pasted into retoken that would override the site's default palette), and it never declares fonts (their url()s would break outside this folder). That is why every page here sets data-theme="termy" on <html>.

Template-only tokens

A styled template may add tokens of its own, prefixed with its name (--neon-glow, --glassy-blur). Termy has none. They live in theme.css so that global.css stays free of colour literals, which tools/check.py enforces.

Light and dark

color-scheme: light dark on :root lets the browser resolve each light-dark() pair from the visitor's preference. The toggle pins color-scheme on <html> instead; the third click unpins it. For things that are not colours (a texture, an ornament, content), theme.js keeps html[data-scheme] equal to the scheme in effect, so CSS can select on it.
