Everything is a prompt.

Green phosphor on a dark green screen by day; the same phosphor on true black by night. One monospace face, no corners, brackets around what you can press, and a CRT overlay you can turn down or off. The markup is the same as every other template here.

What you get

Take the css/, js/theme.js and assets/ folders and you have the whole template. Everything else on this page exists to show it off. The three cards below are the ordinary card, with an image, an icon, and neither; every title is a comment and every button is a bracketed command.

Two stylesheets

theme.css holds the tokens and the palette; global.css holds everything that uses them. Nothing else to load.

Light and dark

Every colour is a light-dark() pair. The toggle in the corner cycles auto, light and dark, and remembers the choice.

Retoken compatible

The palette block in theme.css pastes straight into a retoken site. See the tokens.

Every template also has one feature card with an effect that suits it. Termy's lifts and shows its accent edge. Hover it.

The feature card

A styled template might make this glow, tilt, invert or flip. Termy keeps it to a lift, because termy is the reference and the reference should be legible.

Questions, folded

Accordions are native <details> elements. Give a group of them the same name and opening one closes the others, with no script.

Does this need a build step?

No. Copy the folder, link the two stylesheets and the one script, and write HTML.

How much JavaScript is there?

About forty lines for the theme toggle, and a one-line onclick on anything that opens a dialog. Everything else is HTML and CSS.

Which browsers?

Anything from 2024 on: the template relies on light-dark(), :has(), popovers and exclusive accordions.

A single accordion stands on its own.

What is in the install set?

css/, js/theme.js, assets/ and, if the template has any, fonts/. The README lists it.

A gallery with a lightbox

Click any image. The lightbox is a <dialog>; the arrows and the thumbnails are termy links, and Esc closes it.

Small parts

Buttons come in three kinds and three sizes. A switch is a checkbox with role="switch". Badges and banners carry status.

Words

Prose is what most pages are made of, so .prose styles every construct a markdown renderer produces: headings, lists, quotes, code, tables, footnotes. The blog post page runs the full test document through it; defaults shows every bare element.

A template is a promise about what markup will look like. The contract is that promise written down.
