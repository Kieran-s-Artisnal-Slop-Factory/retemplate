commands

Seven verbs.

Everything shelf does is one of these. Each takes --help.

the reference

commanddoessince
add "text"writes a new numbered note1.0
find querylists notes matching the query1.0
show Nprints note N1.0
edit Nopens note N in $EDITOR1.2
link N Mlinks two notes both ways2.4
rm Nmoves note N to the bin1.0
synccommits and pushes the folder2.0

the bin

Removed notes wait thirty days in ~/notes/.bin. Emptying it is the one thing shelf asks about first.

Empty the bin?

Four notes go for good. This is the only destructive command in shelf, and the only one with a dialog.

flags every command takes

--json

Machine output, one object per line. For piping into jq or into another tool.

--dir path

Another notes folder for this one call. Handy for a work shelf and a home shelf.
