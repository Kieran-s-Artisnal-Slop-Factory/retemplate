install

One line, any shell.

shelf is a single binary. The script below checks your platform, puts it on your path and prints the first command to try.

the script

install
$ curl -fsSL https://example.invalid/shelf.sh | sh
detecting platform… linux/amd64
fetching shelf 2.4… ✓
✓ installed to ~/.local/bin/shelf
try: shelf add "hello"

or by package manager

homebrew

brew install shelf

cargo

cargo install shelf-cli

nix

nix run nixpkgs#shelf
