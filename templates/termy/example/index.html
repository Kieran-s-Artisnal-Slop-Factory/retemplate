shelf 2.4 · notes for people who live in the shell

Your notes, one command away.

shelf keeps every note as a plain text file in a folder you own. Add, find and link from the prompt; sync with git when you want to. Nothing leaves the terminal unless you tell it to.

install read the commands
~/notes
$ shelf add "call the landlord about the boiler"
✓ 0042  tagged: home
$ shelf find boiler
0042  call the landlord about the boiler
0031  boiler service is due in march
$ shelf link 0042 0031
✓ linked

three things it does

plain files

Every note is Markdown in ~/notes. Open the folder in anything else and they are all there, numbered and dated.

find, fast

shelf find greps the folder with an index it keeps up to date. Ten thousand notes answer in under a tenth of a second.

links, not folders

Link two notes by number and each lists the other. There is no tree to tend.

questions from the issue tracker

Does it need a daemon?

No. shelf runs when you call it and exits. The index is a file; it is rebuilt if it goes stale.

Can I turn the screen effect off?

This site's CRT overlay is a class on the body. shelf itself draws nothing but text.

Where does sync go?

Anywhere git goes. shelf sync is git add, commit and push with a sensible message.

i

shelf 2.4 adds the link command and drops the config file. See the commands page.
