Tokens and the palette

Everything in Modern Frosty is coloured through tokens. Nineteen palette slots hold the actual colours, each as a light and dark pair; a layer of semantic tokens maps roles onto them; components only ever name a role. This is retoken's system, so the palette below is also a retoken theme.

Use this palette in retoken

Copy the block below into your retoken site's theme.css after the existing palettes, then select it with <html data-theme="modern-frosty"> or pick it in the theme editor, which discovers palettes from the stylesheet. Colours travel; fonts, radii and spacing do not; set those in the editor.

:root[data-theme='modern-frosty'],
[data-theme='modern-frosty'] {
  --pal-bg0: light-dark(#f4f7fb, #0f1a27);
  --pal-bg0-soft: light-dark(#ffffff, #152232);
  --pal-bg1: light-dark(#e9f0f7, #1b2b3d);
  --pal-bg2: light-dark(#d2dfeb, #2b3f55);
  --pal-bg3: light-dark(#a8bdd1, #42597a);

  --pal-fg: light-dark(#142130, #e7eef6);
  --pal-fg-muted: light-dark(#506478, #a2b4c8);
  --pal-gray: light-dark(#7f92a5, #6e829a);

  --pal-red: light-dark(#b42318, #f0857b);
  --pal-green: light-dark(#157347, #6fcf97);
  --pal-yellow: light-dark(#946200, #e4b85a);
  --pal-blue: light-dark(#2569b3, #8cc0f0);
  --pal-purple: light-dark(#5b4bc4, #b5a8f2);
  --pal-aqua: light-dark(#0f7b8a, #6ed2df);

  --pal-accent: light-dark(#1c5aa3, #8cc0f0);
  --pal-accent-strong: light-dark(#154a89, #b4d8f8);
  --pal-on-accent: light-dark(#ffffff, #0b1622);

  --pal-shadow-1: light-dark(rgb(20 33 48 / 0.06), rgb(0 0 0 / 0.45));
  --pal-shadow-2: light-dark(rgb(20 33 48 / 0.16), rgb(0 0 0 / 0.6));
}

Two things the block deliberately does not do: it never declares a bare :root (pasted into retoken that would override the site's default palette), and it never declares fonts (their url()s would break outside this folder). That is why every page here sets data-theme="modern-frosty" on <html>.

Template-only tokens

Nine tokens of the template's own, prefixed --modern-frosty-. They live in theme.css beside the palette so that global.css stays free of colour literals, which tools/check.py enforces. They are not part of the retoken paste-in.

Light and dark

color-scheme: light dark on :root lets the browser resolve each light-dark() pair from the visitor's preference. The toggle pins color-scheme on <html> instead; the third click unpins it. For things that are not colours (a texture, an ornament, content), theme.js keeps html[data-scheme] equal to the scheme in effect, so CSS can select on it.
