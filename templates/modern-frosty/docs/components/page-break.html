Component

Page break

A thematic break. The bare <hr> is a rule; .page-break is the template's ornament, which here is a short centred rule with one blue point.

Preview

<p>Before the break.</p>
<hr>
<p>After the break.</p>

Variants

Ornamented

<p>Before the break.</p>
<hr class="page-break">
<p>After the break.</p>

Classes

The rules live in css/global.css under /* == page-break == */.

ClassPurpose
hrA one-pixel rule with vertical space
hr.page-breakNo rule; an ornament drawn with ::after

Notes

  • Both are the same element, so both mean the same thing to a screen reader: a break between sections.
  • The ornament is generated content; change the content string in the stylesheet to change it.
