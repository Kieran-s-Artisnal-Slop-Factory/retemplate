Component

Badge

A small label for a state: neutral, active, done.

Preview

<div class="row">
  <span class="badge">Draft</span>
  <span class="badge badge-active">Active</span>
  <span class="badge badge-done">Done</span>
</div>

Classes

The rules live in css/global.css under /* == badge == */.

ClassPurpose
.badgeSmall, bold, pill-shaped, bordered
.badge-activeAccent-tinted
.badge-doneSuccess-tinted

Notes

  • Badges are text. If a badge is the only way a state is conveyed, make sure the text says so.
  • Tags on a blog post use a different class, .tag, because they are links.
