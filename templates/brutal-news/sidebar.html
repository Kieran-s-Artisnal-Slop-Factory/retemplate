Layout · Sidebar

The same paper, with the index down the side

Every template ships two layouts. The overview, the blog post and the forms page use the navbar; this page and the docs use the sidebar. Here the sidebar is a column ruled off from the page with a thick line, like the index of a broadsheet.

What the layout is made of

A grid with two rows and, above 64rem, two columns. The top bar spans both columns and stays put. The sidebar is a sticky column with its own scrollbar; the page scrolls under it. Each navigation group is a <details>, open by default, and the link to the page you are on is printed in red.

Below 64rem the sidebar carries the popover attribute, so the menu button is a real button that opens it, and the browser supplies the backdrop and the dismiss behaviour. Nothing on this page needs the sidebar: swap the shell for the navbar and the content still works.

How the block is built

In brief

Can the sidebar collapse on a wide screen?

Not in this version. The drawer behaviour is for narrow screens only.

Why is everything so loud?

Because a newspaper is read at arm's length in bad light. Thick rules and heavy type survive that; delicate ones do not.
