The other layout

The overview, with a sidebar

Every template ships two layouts. The navbar layout is on the overview, the blog post and the forms page; this page and the docs use the sidebar layout. Here the sidebar is a column ruled off from the page with a thick line, like the index of a broadsheet.

What the layout is made of

A grid with two rows and, above 64rem, two columns. The top bar spans both columns and stays put; the sidebar is a sticky column with its own scrollbar; the page scrolls under it. Below 64rem the sidebar carries the popover attribute, so the menu button is a real button that opens it, and the browser supplies the backdrop and the dismiss behaviour.

Groups fold

Each navigation group is a <details>, open by default.

Same content, either way

Nothing on this page needs the sidebar. Swap the shell and the page still works.

The rest of the kit, briefly

Newspapers learned a long time ago that a page is easier to read in columns. The measure stays short, the eye never travels far, and a rule between the columns keeps the two from bleeding into each other.

The drop cap is generated by the stylesheet from the first letter of the first paragraph; there is nothing extra in the markup.

Docs
Can the sidebar collapse on a wide screen?

Not in this version. The drawer behaviour is for narrow screens only.

Why is everything so loud?

Because a newspaper is read at arm's length in bad light. Thick rules and heavy type survive that; delicate ones do not.
