Table

A data table in a wrapper that scrolls sideways when the table is wider than the page.

Preview

<div class="table-wrap">
  <table class="data-table">
    <thead><tr><th>Name</th><th>Role</th><th>Status</th></tr></thead>
    <tbody>
      <tr><td>Ada</td><td>Analyst</td><td><span class="badge badge-active">Active</span></td></tr>
      <tr><td>Grace</td><td>Compiler</td><td><span class="badge badge-done">Done</span></td></tr>
      <tr><td>Margaret</td><td>Engineer</td><td><span class="badge">Draft</span></td></tr>
    </tbody>
  </table>
</div>

Variants

Scoreboard

Add brutal-news-scoreboard to the wrapper for results, prices and anything else that is mostly numbers. The table sets in JetBrains Mono with tabular figures, every column after the first aligns right, the head prints in reverse, and the wrapper loses its side borders so the rules run edge to edge. The first column is bold; it is the row's name.

<div class="table-wrap brutal-news-scoreboard">
  <table class="data-table">
    <thead><tr><th>Fixture</th><th>Home</th><th>Away</th><th>Gate</th></tr></thead>
    <tbody>
      <tr><td>Ashcombe Town v Hadley Wanderers</td><td>0</td><td>3</td><td>412</td></tr>
      <tr><td>Ashcombe Reserves v Coldwell</td><td>2</td><td>2</td><td>86</td></tr>
      <tr><td>Ashcombe Ladies v Stanton Green</td><td>1</td><td>0</td><td>203</td></tr>
    </tbody>
  </table>
</div>

Classes

The rules live in css/global.css under /* == table == */.

ClassPurpose
.table-wrapBorder, radius, horizontal scrolling
.data-tableSmall type, hover rows, no last border
.brutal-news-scoreboardBrutal News only, on the wrapper: mono figures right-aligned, head in reverse (rules under /* == flare == */)

Notes

  • Use <th> in the head row, and scope="row" on a first-column header if rows have one.
  • Tables inside .prose get the same treatment without the classes.
  • Every row rule is three pixels, in the scoreboard and out of it. A long table is loud; that is the template.
