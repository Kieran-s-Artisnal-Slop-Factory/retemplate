Flare

Flare is everything a template adds beyond the contract. Brutal News adds the furniture of a newspaper: a masthead with a dateline, columned text with a drop cap, a strip of tape, a ruled box and a red block.

Masthead

The title of the paper, ruled top and bottom, with a dateline. It is markup, so it lives inside the .brutal-news-flare wrapper a template swap strips.

<div class="brutal-news-flare">
  <header class="brutal-news-masthead">
    <p class="kicker">Late edition</p>
    <h1>The Daily Rule</h1>
    <p class="brutal-news-dateline"><span>Vol. 1 · No. 12</span><span>Thursday 4 September 2026</span><span>Free</span></p>
  </header>
</div>

Columns and a drop cap

Two columns above 40rem with a rule between them; one below. The drop cap is ::first-letter on the first paragraph.

<div class="brutal-news-columns">
  <p class="brutal-news-dropcap">Newspapers learned a long time ago that a page is easier to read in columns. The measure stays short, the eye never travels far, and a rule between the columns keeps the two from bleeding into each other.</p>
  <p>The drop cap is generated by the stylesheet from the first letter of the first paragraph; there is nothing extra in the markup.</p>
</div>

Tape

<p><span class="brutal-news-tape">Breaking</span> Acid yellow tape for the one word that has to be seen first.</p>

Ruled box

<div class="brutal-news-box">
  <p class="kicker">Ruled box</p>
  <p>A heavy border and a hard shadow. Use it for a pull quote, a notice, an advert.</p>
</div>

Red block

<div class="brutal-news-red">
  <h2>A red block</h2>
  <p>Solid brand colour with paper-coloured type, for a section that has to shout.</p>
</div>

Classes

The rules live in css/global.css under /* == flare == */.

ClassPurpose
.brutal-news-mastheadHeavy rule above, standard rule below, centred
.brutal-news-datelineMono, uppercase, spread across the width
.brutal-news-columnsTwo ruled columns; one on narrow screens
.brutal-news-dropcapFloats the first letter, four and a half lines tall
.brutal-news-tapeAcid yellow strip, slightly rotated
.brutal-news-boxHeavy border and a hard shadow
.brutal-news-redSolid brand colour, paper-coloured type
.brutal-news-flareThe wrapper for flare that is markup

Notes

  • The rule weights are two tokens, --brutal-news-rule (3px) and --brutal-news-rule-heavy (6px). The yellow and the red are tokens too, so nothing in global.css names a colour.
  • The tape's rotation is a transform, not an animation; there is nothing to pause for reduced motion.
  • Column text reflows with the viewport; long unbreakable strings (URLs, code) inside columns may overflow — keep those out of .brutal-news-columns.
