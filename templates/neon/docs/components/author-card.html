Component

Author card

The author, the date and the tags of a post. It sits in the post header; blog anatomy shows the whole shell.

Preview

<aside class="author-card">
  <img class="avatar" src="../../assets/avatar.svg" alt="" width="96" height="96">
  <div>
    <strong class="author-name">Ada Example</strong>
    <p class="author-bio">Writes the test documents every template has to survive.</p>
    <p class="meta"><time datetime="2026-09-04">4 September 2026</time> · <span>6 min read</span></p>
    <p class="tags"><a class="tag" href="#">markdown</a><a class="tag" href="#">fixtures</a></p>
  </div>
</aside>

Classes

The rules live in css/global.css under /* == author-card == */.

ClassPurpose
.author-cardFlex row on a surface with a border
.avatarRound, fixed size
.author-nameDisplay face, larger
.author-bioMuted
.metaSmall, muted; holds the time and reading time
.tagsWrapping row of tags
.tagPill-shaped link, accent-tinted

Notes

  • The avatar is decorative (alt=""); the name is the text.
  • Use a real <time datetime> so the date is machine-readable.
