Component

Footer

Columns of links and a closing note, at the bottom of every navbar page.

Preview

The overview page, live; scroll the frame to the bottom.

Taken from index.html.

Classes

The rules live in css/global.css under /* == footer == */.

ClassPurpose
.footerRaised surface, top border, muted small text; pushed to the bottom
.footer-columnsAuto-fitting columns
.footer section h2Column heading
.footer-noteThe closing line, ruled off

Notes

  • Each column is a <section> with a heading; screen readers get a list of named sections.
  • The footer is the last thing in <body>, and the body is a flex column, so short pages still push it to the bottom.
