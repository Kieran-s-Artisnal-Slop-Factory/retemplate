Component

Dialog

A native <dialog> in modal mode: the page behind is dimmed and inert, focus stays inside, and Esc closes it. A form with method="dialog" closes it too, and reports which button was pressed.

Preview

<button class="btn btn-primary" type="button" onclick="document.getElementById('ex-modal').showModal()">Open the dialog</button>
<dialog class="modal" id="ex-modal" aria-labelledby="ex-modal-title">
  <h2 id="ex-modal-title">Delete this draft?</h2>
  <p>This cannot be undone.</p>
  <form method="dialog" class="modal-actions">
    <button class="btn" type="submit">Cancel</button>
    <button class="btn btn-danger" type="submit" value="delete">Delete</button>
  </form>
</dialog>

Classes

The rules live in css/global.css under /* == dialog == */.

ClassPurpose
.modalThe dialog: surface, border, radius, width, shadow
.modal-actionsThe button row, right-aligned
::backdropThe dimmed page behind (in the base section)

Notes

  • The opener's onclick is the one line of script the contract allows for this. The declarative opener (commandfor) is newer than the browsers this template targets.
  • Buttons inside <form method="dialog"> close the dialog; their value becomes dialog.returnValue if you ever want to read it.
  • Give the dialog aria-labelledby pointing at its heading.
