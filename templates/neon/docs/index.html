Get started

Take the folder. Keep four things.

Neon is complete as it stands: two stylesheets, one small script, a folder of art and two fonts by link. Nothing to install, nothing to build.

1. Copy the folder

Copy templates/neon/ into your project. Inside it, two sets of files.

Keep: the install set

  • css/theme.css: tokens, the palette, the glow colours
  • css/global.css: every component and layout
  • js/theme.js: the scheme toggle
  • assets/: favicon and placeholder art, yours to replace
  • README.md

Delete: the showcase

  • index.html, blogpost.html, forms.html, sidebar.html
  • docs/: these pages
  • example/: a three-page SaaS status site (status, pricing, changelog), unless you start from it
  • js/copy.js: only the docs use it

2. Put this at the top of every page

Adjust the relative paths for pages in sub-folders (../css/theme.css and so on). The script stays a plain, synchronous script above the stylesheets; that is what applies the stored scheme before first paint. The three font lines come last so the page paints in the fallback stack while they load.

<!doctype html>
<html lang="en" data-theme="neon">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <meta name="color-scheme" content="light dark">
  <title>My page</title>
  <link rel="icon" href="assets/favicon.svg">
  <script src="js/theme.js"></script>
  <link rel="stylesheet" href="css/theme.css">
  <link rel="stylesheet" href="css/global.css">
  <link rel="preconnect" href="https://fonts.googleapis.com">
  <link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
  <link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Inter:wght@400;500;600;700&family=Space+Grotesk:wght@500;700&display=swap">
</head>
<body>
  <!-- your page -->
</body>
</html>

3. Write HTML

Use the classes under Components. Wrap article text in <div class="prose"> and every markdown construct is styled; put a page in <main class="page"> and it gets a readable width. The example site is a small real site built this way; the blog post is a rendered article.

4. Light what matters

Neon's rule: glow is state. A lit tube is on, a hairline is off. The classes that carry it are on the flare page: .neon-text turns a headline into the sign, .neon-panel-lit lights one card in a row, .badge.neon-light is a lamp, .neon-status makes a table a board. Light one thing per view.

Starting from the example instead

Copy example/ next to css/, js/ and assets/, delete the rest, and fix the three pages' relative paths (they point one folder up). Everything the example uses is documented here.

The scheme toggle

Every page has a <button class="scheme-toggle">. It cycles auto, light, dark, auto, and stores the choice under the key retoken-scheme, the key a retoken site uses, so the two agree on one origin. Colours follow light-dark() pairs; anything that is not a colour can key off html[data-scheme="dark"], which the script keeps equal to the scheme in effect.

Browsers

Anything current as of 2024: light-dark(), :has(), popovers, exclusive <details name> groups, color-mix() and @property for the feature card's turning border. No polyfills. Where @property is missing the border still lights; it does not turn.

Fonts

Two. Space Grotesk for the sign, headings, the brand, labels and table heads; Inter for everything else. They come from Google Fonts through the three <link> lines in the head block. theme.css names them with a system fallback, so a page reads before they arrive or if they never do.

To self-host, download both families (they are OFL), put the woff2 files in a fonts/ folder beside css/, add @font-face rules at the top of css/global.css pointing at ../fonts/…, and drop the three lines. The README repeats these steps.

Zinc, and black

Neon has no white. The light half is zinc, #18181b with surfaces stepping up from it; the dark half is black, #141414. Text is off-white in both, and the same rose and cyan sit on both grounds; the rose clears 4.5:1 on each. Because both halves are dark, global.css pins select, input, textarea, dialog and open popovers to color-scheme: dark and sets the scrollbar colours: the browser never paints a white menu, picker or rail. Inside those elements the palette resolves to its dark half in either scheme, so a form field is always a black well. See the forms page with the toggle set to light.

Two lines to delete

Each showcase page carries <a class="site-link" href="../../index.html">All templates</a> in its navbar and sidebar: a link back to the retemplate landing. Remove it; nothing else in the folder points outside.

The dialogs and the lightbox open with a one-line onclick. Under a strict Content-Security-Policy that blocks inline handlers, move those calls into theme.js (or any script of yours) as click listeners.

Using the theme in retoken

The palette block in theme.css is a retoken theme. The theme page shows it with a copy button and the one line that turns it on.
