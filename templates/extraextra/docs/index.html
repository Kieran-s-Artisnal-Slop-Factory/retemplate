Get started

Take the folder, keep four things

ExtraExtra is a complete template: two stylesheets, one small script, a folder of art and three fonts from Google. There is nothing to install and nothing to build.

1. Copy the folder

Copy templates/extraextra/ into your project. Inside it, two sets of files:

Keep: the install set

  • css/theme.css: the tokens, the palette and the one orange
  • css/global.css: every component, the bands and the ticker
  • js/theme.js: the light/dark toggle
  • assets/: favicon and poster art (swap for your own)
  • README.md

Delete: the showcase

  • index.html, blogpost.html, forms.html, sidebar.html
  • docs/: these pages
  • example/: The Kiln, a three-page venue site, unless you want to start from it
  • js/copy.js: only the docs use it

2. Put this at the top of every page

Adjust the relative paths for pages in sub-folders (../css/theme.css and so on). The script must stay a synchronous script above the stylesheets: that is what applies the stored scheme before the first paint. The three font lines come last.

<!doctype html>
<html lang="en" data-theme="extraextra">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <meta name="color-scheme" content="light dark">
  <title>My page</title>
  <link rel="icon" href="assets/favicon.svg">
  <script src="js/theme.js"></script>
  <link rel="stylesheet" href="css/theme.css">
  <link rel="stylesheet" href="css/global.css">
  <link rel="preconnect" href="https://fonts.googleapis.com">
  <link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
  <link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Anton&family=Barlow:ital,wght@0,400;0,500;0,700;1,400&family=IBM+Plex+Mono:wght@400;600&display=swap">
</head>
<body>
  <!-- your page -->
</body>
</html>

3. Write HTML

Use the classes documented under Components. Wrap article text in <div class="prose"> and every markdown construct is styled; put a page in <main class="page"> and it runs edge to edge with a gutter. Put a section in <section class="extraextra-band"> and it is an orange band. The example site is a small real site built this way, and the blog post is what a rendered article looks like.

Starting from the example instead

Copy example/ next to css/, js/ and assets/, delete the rest, and fix the three pages' relative paths (they currently point one folder up). Everything the example uses is documented here.

The theme toggle

Every page has a <button class="scheme-toggle">. It cycles auto, light, dark, auto and stores the choice under the key retoken-scheme, the same key a retoken site uses, so the two agree when they share an origin. Colours follow light-dark() pairs; the orange is the one colour that is not a pair, because it is the same in both schemes.

Browsers

Anything current as of 2024: the template uses light-dark(), :has(), popovers, exclusive <details name> groups, color-mix() and mix-blend-mode, with no polyfills.

Fonts

Three, from Google Fonts: Anton for everything set in capitals, Barlow for the body, IBM Plex Mono for labels, data and the ticker. Remove the three <link> lines and the fallback stacks in theme.css take over: Impact for the display, your system sans and mono for the rest. To self-host, download the families, put the files in fonts/, add @font-face rules at the top of css/global.css (not theme.css, whose palette block is pasted elsewhere) and drop the links.

Two lines to delete

Each showcase page carries <a class="site-link" href="../../index.html">All templates</a> in its navbar and sidebar, a link back to the retemplate landing. Remove it; nothing else in the folder points outside.

The dialogs and the lightbox open with a one-line onclick. Under a strict Content-Security-Policy that blocks inline handlers, move those calls into theme.js (or any script of yours) as click listeners.

Using the theme in retoken

The palette block in theme.css is a retoken theme. The theme page shows it with a copy button and the one line that turns it on.
