Component

Banner

A message with a coloured edge: success, info, warning, danger, or none.

Preview

<div class="stack">
  <div class="banner banner-success" role="status"><span>✓</span><p>Saved. Your changes are live.</p></div>
  <div class="banner banner-info" role="status"><span>i</span><p>Nothing to do here yet.</p></div>
  <div class="banner banner-warning" role="status"><span>!</span><p>This draft has unsaved changes.</p></div>
  <div class="banner banner-danger" role="alert"><span>×</span><p>The upload failed. Try again.</p></div>
</div>
<div class="banner"><span>·</span><p>A banner with no tone at all.</p></div>

Variants

Strip (ExtraExtra)

Add extraextra-strip and the banner runs edge to edge as an ink strip, with its first child set as an orange label in display capitals instead of an icon. It ignores the colour modifiers: a strip is for the one notice a page must not let you miss, and it is always ink and orange. Put it directly inside main.page so it can cancel the gutter.

<div class="banner extraextra-strip" role="status"><span>Tonight</span><p>Doors 7. Bands 8. No re-entry after 10.</p></div>

Classes

The rules live in css/global.css under /* == banner == */.

ClassPurpose
.bannerA ruled strip with a ten-pixel left edge, flex with a gap for the icon
.banner-successGreen edge, faint green tint
.banner-infoBlue
.banner-warningYellow
.banner-dangerRed
.extraextra-stripExtraExtra only: full-bleed ink strip with an orange label (global.css § flare)

Notes

  • Use role="status" for messages that can wait and role="alert" for ones that cannot; screen readers announce alerts immediately.
  • The first child is the icon slot; any short string or inline SVG works.
