Tokens and the palette

Everything in Cattle is coloured through tokens. Nineteen palette slots hold the actual colours, each as a light and dark pair; a layer of semantic tokens maps roles onto them; components only ever name a role. This is retoken's system, so the palette below is also a retoken theme.

Use this palette in retoken

Copy the block below into your retoken site's theme.css after the existing palettes, then select it with <html data-theme="cattle"> or pick it in the theme editor, which discovers palettes from the stylesheet. Colours travel; the fonts, the grain, the burn and the leather do not; set type and shape in the editor. The light accent is saddle brown, which carries text on maple but not on dark leather, so the dark accent is brass.

:root[data-theme='cattle'],
[data-theme='cattle'] {
  --pal-bg0: light-dark(#e8d9bf, #2a1a12);
  --pal-bg0-soft: light-dark(#f0e4cd, #33221a);
  --pal-bg1: light-dark(#dcc9a6, #3d2a20);
  --pal-bg2: light-dark(#c4ad83, #553b2d);
  --pal-bg3: light-dark(#9e8660, #74533f);

  --pal-fg: light-dark(#2a1a12, #efe2c8);
  --pal-fg-muted: light-dark(#6b5340, #c9b08e);
  --pal-gray: light-dark(#8c7a62, #9a8368);

  --pal-red: light-dark(#9c2a1e, #e08a72);
  --pal-green: light-dark(#4e6b2f, #a3bf7a);
  --pal-yellow: light-dark(#8a5a12, #e0b866);
  --pal-blue: light-dark(#3f5c7a, #93aecb);
  --pal-purple: light-dark(#6d4a6a, #bb9cc0);
  --pal-aqua: light-dark(#2f6b62, #8ec2b4);

  --pal-accent: light-dark(#7a3b17, #d9a65a);
  --pal-accent-strong: light-dark(#5a2a0e, #e8bd78);
  --pal-on-accent: light-dark(#f3e7cf, #2a1a12);

  --pal-shadow-1: light-dark(rgb(42 26 18 / 0.16), rgb(0 0 0 / 0.45));
  --pal-shadow-2: light-dark(rgb(42 26 18 / 0.28), rgb(0 0 0 / 0.65));
}

Two things the block deliberately does not do: it never declares a bare :root (pasted into retoken that would override the site's default palette), and it never declares fonts (their url()s would break outside this folder). That is why every page here sets data-theme="cattle" on <html>.

Light and dark

color-scheme: light dark on :root lets the browser resolve each light-dark() pair from the visitor's preference. The toggle pins color-scheme on <html> instead; the third click unpins it. Cattle needs no data-scheme hook: the burn and the tooling are one text-shadow list whose layers are colours, so each half's layers fade to transparent in the other, and the swap from grain to leather on body is a veil that is bg0 by day and nothing by night. Both survive the retoken paste-in.
