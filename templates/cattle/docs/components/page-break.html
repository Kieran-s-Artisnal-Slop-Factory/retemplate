Component

Page break

A thematic break. The bare <hr> is a thin burnt rule; .page-break is the maker's mark burnt between two rules; cattle-rope is a length of hemp rope for a break between subjects.

Rope (Cattle)

Two strands of hemp, the full width of the column. Use it where the page changes subject; use the mark for a break inside one. A swap to another template leaves an ordinary rule.

Classes

The rules live in css/global.css under /* == page-break == */.

ClassPurpose
hrA two-pixel burnt rule with a scorch (--cattle-burn-rule) and vertical space
hr.page-breakTwo burnt rules as background gradients, the steer mark as a mask on ::after, one drop-shadow scorching both
hr.cattle-ropeCattle only: a repeating gradient in the two rope tokens

Notes

  • All three are the same element, so all three mean the same thing to a screen reader: a break between sections.
  • The mark is the --cattle-mark token in theme.css, filled with --cattle-char: charred by day, cream by night. Replace the token to put your own mark on every page break.
  • On leather (inside .cattle-leather or the chrome) the rules and the mark come out in cream with no scorch.
