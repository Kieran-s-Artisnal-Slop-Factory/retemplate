The other layout

The overview, beside a sidebar

Every template ships two layouts. The navbar layout is on the overview, the blog post and the forms page; this page and the docs use the sidebar layout. Here the sidebar is a tall sheet of glass with the orbs showing through it, and the page is the same three depths, in a narrower column.

What the layout is made of

A grid with two rows and, above 64rem, two columns. The top bar spans both and stays put; the sidebar is a sticky column with its own scrollbar; the page scrolls beside it. Below 64rem the sidebar carries the popover attribute, so the menu button is a real button that opens it, and the browser supplies the blurred backdrop and the dismiss behaviour.

Groups fold

Each navigation group is a <details>, open by default. Close the ones you are not using.

The current page

The link to the page you are on carries aria-current="page" and a tinted pill.

Same content, either way

Nothing on this page needs the sidebar. Swap the shell and the page still works.

Glass on glass

Sheets stack. A card inside a pane inside the page still reads, because each sheet takes only some of the light behind it. The pane below holds a shallow card and a deep one.

How it is built
Can the sidebar collapse on a wide screen?

Not in this version. The drawer behaviour is for narrow screens only.

Does the blur cost anything?

A little, on old hardware. Every sheet is a backdrop-filter; if a page has hundreds, lower --glassy-blur in theme.css.
