Sidebar

The docs layout: a sticky top bar, a navigation column that becomes a drawer on small screens, and the page. The sidebar variant is the overview inside it.

Preview

The sidebar variant, live. Narrow the frame below 64rem to see the drawer.

Classes

The rules live in css/global.css under /* == sidebar == */.

ClassPurpose
.sidebar-layoutThe grid: one column below 64rem, two above
.topbarSticky bar spanning both columns
.sidebar-toggleOpens the drawer; hidden on wide screens
.sidebarThe column, or the popover drawer
.sidebar nav detailsA collapsible group of links
a[aria-current=page]The current page
.sidebar-footerPushed to the bottom of the column

Notes

  • Below 64rem the aside is a popover: a real button opens it, the browser dims the page and closes it on Esc or a click outside. Above 64rem it is a sticky column and the attribute is inert.
  • There is no collapse on wide screens in this version.
  • Every sidebar page carries the same links, in the same groups; the checker compares them.
