Component

Navbar

The sticky header used by the overview, the blog post and the forms page: a brand, the site links, the scheme toggle, and a menu button that turns the links into a popover on small screens.

Preview

The overview page, live. Narrow the frame to see the menu button.

Markup

Taken from index.html. The link to the current page carries aria-current="page".

<header class="navbar glassy-floating">
  <a class="brand" href="index.html">Glassy</a>
  <button class="nav-toggle" type="button" popovertarget="site-nav" aria-label="Menu">☰</button>
  <nav id="site-nav" popover>
    <a href="index.html" aria-current="page">Overview</a>
    <a href="blogpost.html">Blog post</a>
    <a href="forms.html">Forms</a>
    <a href="sidebar.html">Sidebar</a>
    <a href="docs/index.html">Docs</a>
    <a href="example/index.html">Example</a>
  </nav>
  <button class="scheme-toggle" type="button" data-scheme="auto" aria-label="Theme: auto"></button>
  <a class="site-link" href="../../index.html">All templates</a>
</header>

Classes

The rules live in css/global.css under /* == navbar == */.

ClassPurpose
.navbarSticky, translucent, blurred, with a bottom border
.glassy-floatingGlassy only: the bar as a detached sheet inset from the edges, with a rounded popover to match (rules under /* == flare == */)
.brandThe site name; pushes everything else right
navThe links; a popover below 48rem, inline above
.nav-toggleThe menu button; hidden above 48rem
.scheme-toggleThe three-state theme button
.site-linkThe one link out of the folder; delete it

Notes

  • Below 48rem the <nav> has the popover attribute and the button opens it with popovertarget. Esc and clicking outside close it; the backdrop is the browser's.
  • Above 48rem the same element is laid out inline; the attribute is simply ignored by the stylesheet.
  • The three navbar pages carry the same link set. Example pages have their own.
  • Every showcase page adds glassy-floating. Leave it off for a bar that runs edge to edge.
