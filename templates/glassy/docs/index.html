All templates

Get started

Take the folder, keep four things

Glassy is a complete template: two stylesheets, one small script, a folder of art. Nothing to install, nothing to build, no fonts to load.

Copy the folder

Copy templates/glassy/ into your project. Inside it, two sets of files:

Keep: the install set

  • css/theme.css, the tokens, the palette and the glass recipe
  • css/global.css, every component and layout
  • js/theme.js, the light/dark toggle
  • assets/, favicon and placeholder art; swap for your own
  • README.md

Delete: the showcase

  • index.html, blogpost.html, forms.html, sidebar.html
  • docs/, these pages
  • example/, the studio site, unless you want to start from it
  • js/copy.js, which only the docs use

Put this at the top of every page

Adjust the relative paths for pages in sub-folders (../css/theme.css and so on). The script must stay a plain, synchronous script above the stylesheets: that is what applies the stored scheme before the first paint.

<!doctype html>
<html lang="en" data-theme="glassy">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <meta name="color-scheme" content="light dark">
  <title>My page</title>
  <link rel="icon" href="assets/favicon.svg">
  <script src="js/theme.js"></script>
  <link rel="stylesheet" href="css/theme.css">
  <link rel="stylesheet" href="css/global.css">
</head>
<body>
  <!-- your page -->
</body>
</html>

Put the orbs behind it

Right after <body>, add the orbs block from the flare page. Glass needs colour behind it; without the orbs the sheets sit on the gradient alone and read flatter than they should.

Write HTML

Use the classes documented under Components. Wrap article text in <div class="prose"> and every markdown construct is styled; put a page in <main class="page"> and it gets a comfortable width. Then compose by depth: one deep sheet for the thing to read first, ordinary sheets for the rest, shallow ones for what should sit back, and glassy-float where one block should hang off the last. The studio site is a small real site built this way, and the blog post is what a rendered article looks like.

Starting from the studio site instead

Copy example/ next to css/, js/ and assets/, delete the rest, and fix the three pages' relative paths (they currently point one folder up). Everything the example uses is documented here.

The theme toggle

Every page has a <button class="scheme-toggle">. It cycles auto, light, dark, auto and stores the choice under the key retoken-scheme, the same key a retoken site uses, so the two agree when they share an origin. Colours follow light-dark() pairs; anything that is not a colour can key off html[data-scheme="dark"], which the script keeps equal to the scheme actually in effect.

Browsers

Anything current as of 2024: the template uses light-dark(), :has(), popovers, exclusive <details name> groups, color-mix() and backdrop-filter, with no polyfills.

Fonts

Glassy uses your system's fonts, so nothing is downloaded. The type is set light at the two large sizes and semibold below them; the labels are small, wide-tracked capitals. If your system has no light weight, the browser falls back to regular and the page still holds.

Two lines to delete

Each showcase page carries <a class="site-link" href="../../index.html">All templates</a> in its navbar and sidebar, a link back to the retemplate landing. Remove it; nothing else in the folder points outside.

The dialogs and the lightbox open with a one-line onclick. Under a strict Content-Security-Policy that blocks inline handlers, move those calls into theme.js (or any script of yours) as click listeners.

Using the theme in retoken

The palette block in theme.css is a retoken theme. The theme page shows it with a copy button and the one line that turns it on.
