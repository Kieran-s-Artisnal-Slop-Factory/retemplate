Tokens and the palette

Everything in Natural is coloured through tokens. Nineteen palette slots hold the actual colours, each as a light and dark pair; a layer of semantic tokens maps roles onto them; components only ever name a role. This is retoken's system, so the palette below is also a retoken theme.

Use this palette in retoken

Copy the block below into your retoken site's theme.css after the existing palettes, then select it with <html data-theme="natural"> or pick it in the theme editor, which discovers palettes from the stylesheet. Colours travel; fonts, radii and spacing do not; set those in the editor.

:root[data-theme='natural'],
[data-theme='natural'] {
  --pal-bg0: light-dark(#ece7d6, #1c150f);
  --pal-bg0-soft: light-dark(#f5f1e4, #261e16);
  --pal-bg1: light-dark(#e3ddc9, #2f261c);
  --pal-bg2: light-dark(#c6c0a8, #47392a);
  --pal-bg3: light-dark(#a89f84, #5f4e3a);
  --pal-fg: light-dark(#2e2519, #ece7d6);
  --pal-fg-muted: light-dark(#6b6450, #b9c9a0);
  --pal-gray: light-dark(#8c8470, #8a7f6b);
  --pal-red: light-dark(#9c2f2f, #d98a74);
  --pal-green: light-dark(#4d6b38, #9fbf7a);
  --pal-yellow: light-dark(#8a6414, #d9b866);
  --pal-blue: light-dark(#3f5f7a, #8fa9bf);
  --pal-purple: light-dark(#6e4f7a, #b39ab8);
  --pal-aqua: light-dark(#2f6f68, #8fbcb2);
  --pal-accent: light-dark(#a33b2a, #e2cf9c);
  --pal-accent-strong: light-dark(#7f2c1f, #f0e2b8);
  --pal-on-accent: light-dark(#f5f1e4, #1c150f);
  --pal-shadow-1: light-dark(rgb(46 37 25 / 0.10), rgb(0 0 0 / 0.45));
  --pal-shadow-2: light-dark(rgb(46 37 25 / 0.18), rgb(0 0 0 / 0.6));
}

Two things the block deliberately does not do: it never declares a bare :root (pasted into retoken that would override the site's default palette), and it never declares fonts (their url()s would break outside this folder). That is why every page here sets data-theme="natural" on <html>.

Light and dark

color-scheme: light dark on :root lets the browser resolve each light-dark() pair from the visitor's preference. The toggle pins color-scheme on <html> instead; the third click unpins it. For things that are not colours (a texture, an ornament, content), theme.js keeps html[data-scheme] equal to the scheme in effect, so CSS can select on it.
