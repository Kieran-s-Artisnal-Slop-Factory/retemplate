Get started

Take the folder, keep four things

Natural is a complete template: two stylesheets, one small script, a folder of art, and two typefaces linked from Google Fonts. There is nothing to install and nothing to build.

1. Copy the folder

Copy templates/natural/ into your project. Inside it, two sets of files:

Keep: the install set

  • css/theme.css — the tokens, the palette, the soil texture and the sprig
  • css/global.css — every component and layout
  • js/theme.js — the light/dark toggle
  • assets/ — favicon and placeholder art (swap for your own)
  • README.md

Delete: the showcase

  • index.html, blogpost.html, forms.html, sidebar.html
  • docs/ — these pages
  • example/ — a three-page plant nursery, unless you want to start from it
  • js/copy.js — only the docs use it

2. Put this at the top of every page

Adjust the relative paths for pages in sub-folders (../css/theme.css and so on). The script must stay a plain, synchronous script above the stylesheets: that is what applies the stored scheme before the first paint. The last three lines load the fonts; see below for doing without them.

<!doctype html>
<html lang="en" data-theme="natural">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <meta name="color-scheme" content="light dark">
  <title>My page</title>
  <link rel="icon" href="assets/favicon.svg">
  <script src="js/theme.js"></script>
  <link rel="stylesheet" href="css/theme.css">
  <link rel="stylesheet" href="css/global.css">
  <link rel="preconnect" href="https://fonts.googleapis.com">
  <link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
  <link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Fraunces:opsz,wght@9..144,400..700&family=Source+Sans+3:ital,wght@0,400;0,600;0,700;1,400&display=swap">
</head>
<body>
  <!-- your page -->
</body>
</html>

3. Write HTML

Use the classes documented under Components. Wrap article text in <div class="prose"> and every markdown construct is styled; put a page in <main class="page"> and it gets a comfortable width. Use <p class="kicker"> above a heading for the tracked moss capitals this template leans on. The example site is a small real site built this way, and the blog post is what a rendered article looks like.

Starting from the example instead

Copy example/ next to css/, js/ and assets/, delete the rest, and fix the three pages' relative paths (they currently point one folder up). Everything the example uses is documented here.

The theme toggle

Every page has a <button class="scheme-toggle">. It cycles auto → light → dark → auto and stores the choice under the key retoken-scheme, the same key a retoken site uses, so the two agree when they share an origin. Colours follow light-dark() pairs. The soil texture under the dark scheme is not a colour, so it is covered by one instead: a layer of light-dark(var(--pal-bg0), transparent) sits between the page and the texture. Anything else that is not a colour can key off html[data-scheme="dark"], which the script keeps equal to the scheme actually in effect.

Browsers

Anything current as of 2024: the template uses light-dark(), :has(), popovers, exclusive <details name> groups, color-mix() and mask-image, with no polyfills.

Fonts

Fraunces (headings, brand, quotes) and Source Sans 3 (everything else) load from Google Fonts through the three <link>s in the head. Both are free under the SIL Open Font License. Without them — offline, or with the links removed — the fallback stacks in theme.css give you Palatino or Georgia and Segoe UI or Helvetica, and nothing breaks. To self-host: download both families, put the files in fonts/, add @font-face rules at the top of css/global.css (not theme.css, whose palette block gets pasted into other sites) and remove the links.

Two lines to delete

Each showcase page carries <a class="site-link" href="../../index.html">All templates</a> in its navbar and sidebar — a link back to the retemplate landing. Remove it; nothing else in the folder points outside.

The dialogs and the lightbox open with a one-line onclick. Under a strict Content-Security-Policy that blocks inline handlers, move those calls into theme.js (or any script of yours) as click listeners.

Using the theme in retoken

The palette block in theme.css is a retoken theme. The theme page shows it with a copy button and the one line that turns it on. The soil, the sprig and the fonts stay here; they are this template's own tokens.
