Calendar

Natural's own variant. Add natural-calendar to the wrapper and the table is a planting calendar: the plant's name in Fraunces italic down the first column, a month per column after it, and a dot per cell. The dots are backgrounds in the feedback colours (natural-sow green, natural-flower rust, natural-lift amber), so they follow the scheme; put the word in a .visually-hidden span so the cell is not empty to a reader. A .natural-legend list under the table explains the colours.

Classes

The rules live in css/global.css under /* == table == */.

ClassPurpose
.table-wrapBorder, radius, horizontal scrolling
.data-tableSmall type, hover rows, no last border
.natural-calendarNatural's variant on .table-wrap: fixed layout, centred cells, italic first column (global.css § flare)
.natural-sow, .natural-flower, .natural-liftA dot in a cell: success, primary and warning colours
.natural-legendAn inline list of the three marks with their dots

Notes

  • Use <th> in the head row, and scope="row" on a first-column header if rows have one.
  • Tables inside .prose get the same treatment without the classes.
  • The calendar is at least 42rem wide and scrolls inside its wrapper on a phone, first column and all; the legend stays put beneath it.
