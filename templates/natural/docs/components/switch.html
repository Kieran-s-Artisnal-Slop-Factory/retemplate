Component

Switch

A checkbox styled as a switch, for settings that are on or off. The input keeps every native behaviour; the class only draws the track and the thumb.

Preview

<label class="switch"><input type="checkbox" role="switch"><span>Email me updates</span></label>

  <label class="switch"><input type="checkbox" role="switch" checked disabled><span>On, disabled</span></label>

Classes

The rules live in css/global.css under /* == switch == */.

ClassPurpose
.switchThe label: inline flex, gap, pointer
input[role=switch]The track, drawn with appearance: none
input::beforeThe thumb, moved with a transform when checked

Notes

  • role="switch" tells assistive technology it is a switch, not a checkbox; the label text is its name.
  • Keyboard: Space toggles; the focus ring is the accent colour.
  • It submits like any checkbox. Give it a name inside a form.
