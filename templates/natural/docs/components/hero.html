Component

Hero

The opening of a page: a heading at the largest size, a paragraph, one or two buttons, and beside them whatever the template leads with. Every template has its own hero form; this page shows Natural's, then two variants that move.

Preview

The hero as the overview uses it. The heading takes --font-size-hero; the paragraph is muted and capped at a readable measure.

Variants

Text only

The same hero with nothing beside the words. Add hero-text: the grid becomes one column and the stack is capped at a readable measure. Every template carries this variant with the same class.

<section class="hero hero-text">
  <div class="stack">
    <p class="kicker">Words only</p>
    <h1>A hero with nothing beside it.</h1>
    <p>One column, the text measure capped so the lines stay readable, and everything else the hero has: the kicker, the heading at the hero size, the paragraph, the buttons.</p>
    <div class="row">
      <a class="btn btn-primary btn-lg" href="../index.html">Get started</a>
      <a class="btn btn-lg" href="index.html">Browse components</a>

Image only

A hero that is one picture, edge to edge, cropped to a wide band. Add hero-image and give it a single <img> (or a <figure>) with a real alt, since there is no heading to say what it is. Every template carries this variant with the same class.

<section class="hero hero-image">
  <img src="../../assets/hero.svg" alt="The template's hero picture, filling the width" width="1200" height="500">
</section>

The growth

A stem draws itself up the page and its leaves unfold from the stalk one after another, in moss and the lighter moss of the tags. It grows once, in about three seconds, and then stands. Add natural-grow to the hero. Under prefers-reduced-motion the global rule cuts every animation to nothing, so the hero is simply there.

<section class="hero natural-grow">
  <div class="stack">
    <p class="kicker">A retemplate template</p>
    <h1>Drawn as it <em>grows</em>.</h1>
    <p>The stem is one path drawing its length; each leaf is a shape that opens from where it meets the stalk. Stroke and fill are the moss tokens, so the plant changes with the scheme.</p>

The canopy

Leaf shadows cross the specimen plate as the light behind them moves: two dark, blurred leaves drift one way over sixteen seconds while a patch of sun drifts the other, so the plate is always half in shade and the shade is always somewhere new. Add natural-dapple to the hero; the global prefers-reduced-motion rule stops it.

<section class="hero natural-dapple">
  <div class="natural-flare">
    <figure class="natural-plate">
      <img src="../../assets/hero.svg" alt="A pressed water avens on a cream herbarium sheet" width="900" height="1100">
      <figcaption class="natural-label">
        <p class="kicker">Herbarium of the Natural template</p>
        <p class="natural-binomial">Geum rivale <span class="natural-auth">L.</span></p>
      </figcaption>
    </figure>
  </div>
  <div class="stack">
    <p class="kicker">A retemplate template</p>
    <h1>Under the <em>canopy</em>.</h1>
    <p>Two leaf shadows in moss drift across the plate and a patch of sun drifts the other way. The shadows multiply into the picture, so they read on paper and on soil alike.</p>

Classes

The rules live in css/global.css: the hero under /* == utilities == */ with the other layout helpers, the variant under /* == hero variants == */.

ClassPurpose
.heroThe opening section: a grid of a text stack and, in most templates, a picture or a piece of flare
.hero .stackThe kicker, heading, paragraph and button row
.hero .rowThe buttons
.hero.natural-growThe hero with the vine beside the text
.natural-vineThe inline SVG
.natural-vine-stemOne path that draws its own length
.natural-vine-leafA leaf; opens from its base after a delay set by --i
.hero.natural-dappleThe plate with leaf shadows and a patch of sun drifting across it
.hero.hero-textWords only: one column, capped measure (every template)
.hero.hero-imagePicture only: one image edge to edge, cropped 21:9 (every template)

Notes

  • One <h1> per page: the hero's heading is it. The kicker above it is a <p>, not a heading.
  • Above 48rem the hero is two columns, text then picture; below, it stacks. The variant keeps whatever layout its markup implies.
  • The variant is CSS only. Its animation is declared with both fill, so the page is correct before it starts and after it ends, and the global prefers-reduced-motion rule stops it.
  • Another template ignores natural-grow and shows its own hero; any flare markup inside sits in the template's flare wrapper so a swap can drop it.
