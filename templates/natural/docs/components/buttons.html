Buttons

Three kinds: primary, default and danger, in three sizes. A link can wear the same classes when it should look like a button.

Preview

<div class="row">
  <button class="btn btn-primary" type="button">Primary</button>
  <button class="btn" type="button">Default</button>
  <button class="btn btn-danger" type="button">Danger</button>
  <a class="btn" href="#">A link</a>
</div>

Variants

Sizes and the disabled state

<div class="row">
  <button class="btn btn-sm" type="button">Small</button>
  <button class="btn" type="button">Regular</button>
  <button class="btn btn-lg" type="button">Large</button>
  <button class="btn btn-primary" type="button" disabled>Disabled</button>
</div>

Stamp

Natural's own variant. natural-stamp on a button or a link makes a rubber stamp: moss ink, a double rule, tracked capitals, no fill. It takes btn-lg; it presses flat on click. The overview and the example site use it for the second action beside a rust primary, so the two never compete.

<div class="row">
  <button class="btn natural-stamp" type="button">Sold</button>
  <button class="btn natural-stamp btn-lg" type="button">Reserved</button>
  <a class="btn natural-stamp" href="#">The field guide</a>
</div>

Classes

The rules live in css/global.css under /* == buttons == */.

ClassPurpose
.btnThe base: inline flex, padding, border, radius, transition
.btn-primaryFilled with the accent
.btn-dangerFilled with the danger colour
.btn-smSmaller padding and type
.btn-lgLarger padding and type
:disabledFaded, not clickable
.natural-stampNatural's variant: a moss rubber stamp with a double rule (global.css § flare)

Notes

  • Every button that does not submit a form carries type="button"; otherwise, inside a form, it submits.
  • Use a <button> for actions and an <a> for navigation, whatever they look like.
  • Group them in .row to get consistent gaps and wrapping.
