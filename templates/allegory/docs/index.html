All templates

Get started

Take the folder, keep three things

Allegory is a complete template: two stylesheets, one small script, a folder of art, and one link to Google Fonts. There is nothing to install and nothing to build. Both faces come from a single palette block, so there is nothing to keep in step either.

Copy the folder

Copy templates/allegory/ into your project. Inside it, two sets of files:

Keep: the install set

  • css/theme.css: the tokens, the palette and the two faces
  • css/global.css: every component and layout
  • js/theme.js: the light/dark toggle
  • assets/: favicon and placeholder art (swap for your own)
  • README.md

Delete: the showcase

  • index.html, blogpost.html, forms.html, sidebar.html
  • docs/: these pages
  • example/: a three-page story site, unless you want to start from it
  • js/copy.js: only the docs use it

Put this at the top of every page

Adjust the relative paths for pages in sub-folders (../css/theme.css and so on). The script must stay a plain, synchronous script above the stylesheets: that is what applies the stored scheme before the first paint, and what sets data-scheme so the ornaments know which drawing to show.

<!doctype html>
<html lang="en" data-theme="allegory">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <meta name="color-scheme" content="light dark">
  <title>My page</title>
  <link rel="icon" href="assets/favicon.svg">
  <script src="js/theme.js"></script>
  <link rel="stylesheet" href="css/theme.css">
  <link rel="stylesheet" href="css/global.css">
  <link rel="preconnect" href="https://fonts.googleapis.com">
  <link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
  <link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Cormorant+Garamond:ital,wght@0,500;0,600;0,700;1,500;1,600&family=Inter:wght@400;500;600;700&display=swap">
</head>
<body>
  <!-- your page -->
</body>
</html>

Write HTML

Use the classes documented under Components. Wrap article text in <div class="prose"> and every markdown construct is styled; put a page in <main class="page"> and it gets a comfortable width. The example site is a small story told in two chapters, and the blog post is what a rendered article looks like.

Use the two faces

By default every element follows the visitor's scheme. Two classes pin an element to one face whatever the scheme: allegory-halo for the day (ivory, gold, wings) and allegory-horn for the night (black, red, horns). Put one on a card, a page header or a section. Put both on the two children of an allegory-diptych and you have the split hero from the overview. Display type that should sit on a band takes allegory-band. All of it is on the flare page.

Starting from the example instead

Copy example/ next to css/, js/ and assets/, delete the rest, and fix the three pages' relative paths (they currently point one folder up). The two chapter pages are mirrors of each other; keep that or break it as the story needs.

The theme toggle

Every page has a <button class="scheme-toggle">. It cycles auto, light, dark, auto, and stores the choice under the key retoken-scheme, the same key a retoken site uses, so the two agree when they share an origin. Colours follow light-dark() pairs; the ornaments key off html[data-scheme="dark"], which the script keeps equal to the scheme in effect.

Browsers

Anything current as of 2024: the template uses light-dark(), :has(), popovers, exclusive <details name> groups, color-mix() and mask-image, with no polyfills.

Fonts

Cormorant Garamond for display and Inter for text, both from Google Fonts through the three <link>s in the head block. Without them the fallbacks are Garamond or Times and Segoe UI or Helvetica. The README says how to self-host: download both families into fonts/, add @font-face rules at the top of global.css, and drop the three links.

Two lines to delete

Each showcase page carries <a class="site-link" href="../../index.html">All templates</a> in its navbar and sidebar, a link back to the retemplate landing. Remove it; nothing else in the folder points outside.

The dialogs and the lightbox open with a one-line onclick. Under a strict Content-Security-Policy that blocks inline handlers, move those calls into theme.js (or any script of yours) as click listeners.

Using the theme in retoken

The palette block in theme.css is a retoken theme. The theme page shows it with a copy button and the one line that turns it on. The colours travel; the wings, horns, bands and fonts stay here.
