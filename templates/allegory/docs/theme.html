Tokens and the palette

Everything in Allegory is coloured through tokens. Nineteen palette slots hold the actual colours, each as a light and dark pair; a layer of semantic tokens maps roles onto them; components only ever name a role. This is retoken's system, so the palette below is also a retoken theme.

Use this palette in retoken

Copy the block below into your retoken site's theme.css after the existing palettes, then select it with <html data-theme="allegory"> or pick it in the theme editor, which discovers palettes from the stylesheet. Colours travel; fonts, radii and spacing do not: set those in the editor.

:root[data-theme='allegory'],
[data-theme='allegory'] {
  --pal-bg0: light-dark(#fbf7ee, #0b0708);
  --pal-bg0-soft: light-dark(#fffdf7, #16100f);
  --pal-bg1: light-dark(#f2ead7, #20171a);
  --pal-bg2: light-dark(#dccfa8, #3d2429);
  --pal-bg3: light-dark(#bfa96e, #5e333d);
  --pal-fg: light-dark(#2a2418, #f3ebe6);
  --pal-fg-muted: light-dark(#6e6246, #b89b98);
  --pal-gray: light-dark(#8f856d, #7d6a6a);
  --pal-red: light-dark(#a8322f, #ff6b6b);
  --pal-green: light-dark(#4a7a3a, #7fbf7a);
  --pal-yellow: light-dark(#8a6d1f, #e0b45a);
  --pal-blue: light-dark(#3e5f8c, #7ea4d8);
  --pal-purple: light-dark(#6b4f8a, #b98cd8);
  --pal-aqua: light-dark(#2f7a78, #66c2b8);
  --pal-accent: light-dark(#8a6d1f, #e0334f);
  --pal-accent-strong: light-dark(#6b5314, #ff5c73);
  --pal-on-accent: light-dark(#fffdf7, #0b0708);
  --pal-shadow-1: light-dark(rgb(138 109 31 / 0.14), transparent);
  --pal-shadow-2: light-dark(rgb(138 109 31 / 0.26), transparent);
}

Two things the block deliberately does not do: it never declares a bare :root (pasted into retoken that would override the site's default palette), and it never declares fonts (their url()s would break outside this folder). That is why every page here sets data-theme="allegory" on <html>.

Template-only tokens

Allegory's own tokens, prefixed --allegory-, live in theme.css after the palette so that global.css stays free of colour literals (which tools/check.py enforces). They are not part of the retoken paste-in. Most are the two faces written out, so that an element can be pinned to one of them.

Light and dark

color-scheme: light dark on :root lets the browser resolve each light-dark() pair from the visitor's preference. The toggle pins color-scheme on <html> instead; the third click unpins it. For things that are not colours, a texture, an ornament, content, theme.js keeps html[data-scheme] equal to the scheme in effect, so CSS can select on it.
