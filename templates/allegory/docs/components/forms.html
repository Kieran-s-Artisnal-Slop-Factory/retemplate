Component

Forms

The .field pattern (label, control, hint or error) and the grid that arranges fields inside fieldsets. Native controls are styled on defaults; the forms page shows every control in one form.

Preview

<div class="field">
  <label for="ex-email">Email</label>
  <input id="ex-email" name="email" type="email" placeholder="you@example.com">
  <p class="hint">We only use it to reply.</p>
</div>

Variants

Invalid

<div class="field field-invalid">
  <label for="ex-user">Username</label>
  <input id="ex-user" name="username" type="text" value="ada lovelace" aria-invalid="true" aria-describedby="ex-user-error">
  <p class="error" id="ex-user-error">Usernames cannot contain spaces.</p>
</div>

A group of checks

<div class="field">
  <span class="field-label">Interests</span>
  <label class="check"><input type="checkbox" name="i" value="design" checked> Design</label>
  <label class="check"><input type="checkbox" name="i" value="code"> Code</label>
</div>

A whole form

<form class="form-grid" action="#" method="get">
  <fieldset>
    <legend>Booking</legend>
    <div class="field">
      <label for="ex-name">Name</label>
      <input id="ex-name" name="name" type="text">
    </div>
    <div class="field">
      <label for="ex-date">Date</label>
      <input id="ex-date" name="date" type="date">
    </div>
    <div class="field field-wide">
      <label for="ex-notes">Notes</label>
      <textarea id="ex-notes" name="notes" rows="3"></textarea>
    </div>
    <div class="field">
      <label class="switch"><input type="checkbox" role="switch" name="remind" checked><span>Remind me</span></label>
    </div>
  </fieldset>
  <div class="form-actions">
    <button class="btn btn-primary" type="submit">Book</button>
    <button class="btn" type="reset">Clear</button>
  </div>
</form>

Classes

The rules live in css/global.css under /* == forms == */.

ClassPurpose
.fieldLabel, control and hint stacked with a small gap
.field > label, .field-labelThe label, small and bold
.hintMuted help text
.errorDanger-coloured message
.field-invalidColours the control's border
.checkA label wrapping a checkbox or radio
.form-gridThe form: a stack of fieldsets
fieldsetTwo columns above 40rem
.field-wideSpans both columns
.form-actionsThe button row

Notes

  • Always pair a <label for> with the control's id. For a group of checks, the group label is a span.field-label and each check has its own label.
  • Mark invalid fields with aria-invalid="true" and point aria-describedby at the error's id; the class only draws the border.
  • Nothing here needs script. Native validation attributes (required, minlength, pattern) work as usual.
