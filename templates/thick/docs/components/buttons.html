Buttons

Three kinds: primary, default and danger, in three sizes, every one outlined and on a solid shadow. Hover lifts a button 2px; holding it down pushes it 4px into the page and the shadow disappears. A link can wear the same classes when it should look like a button.

Preview

<div class="row">
  <button class="btn btn-primary" type="button">Primary</button>
  <button class="btn" type="button">Default</button>
  <button class="btn btn-danger" type="button">Danger</button>
  <a class="btn" href="#">A link</a>
</div>

Variants

Sizes and the disabled state

<div class="row">
  <button class="btn btn-sm" type="button">Small</button>
  <button class="btn" type="button">Regular</button>
  <button class="btn btn-lg" type="button">Large</button>
  <button class="btn btn-primary" type="button" disabled>Disabled</button>
</div>

Flat (Thick)

thick-flat takes the shadow away, for a row of small actions where a dozen shadows would be noise. It keeps the outline, turns yellow on hover and still presses, by 2px instead of 4.

<div class="row">
  <button class="btn thick-flat" type="button">Edit</button>
  <button class="btn thick-flat" type="button">Duplicate</button>
  <button class="btn thick-flat" type="button">Archive</button>
  <button class="btn thick-flat btn-sm" type="button">Small and flat</button>
</div>

Classes

The rules live in css/global.css under /* == buttons == */.

ClassPurpose
.btnThe base: inline flex, padding, border, radius, transition
.btn-primaryFilled with the accent
.btn-dangerFilled with the danger colour
.btn-smSmaller padding and type
.btn-lgLarger padding and type
:disabledFaded, no shadow, not clickable
.thick-flatNo shadow; presses 2px (Thick)

Notes

  • Every button that does not submit a form carries type="button"; otherwise, inside a form, it submits.
  • Use a <button> for actions and an <a> for navigation, whatever they look like.
  • Group them in .row to get consistent gaps and wrapping.
  • On a yellow surface (the hero, the band, a thick-yellow block) the primary button turns to ink, since yellow on yellow would vanish.
  • The press is a 120ms transition; under prefers-reduced-motion it jumps instead.
